# Waste-Watch-IoT-App

# Description
- The WasteWatch web/mobile application will provide clear and reliable schedules for door-to-door garbage collection, showing exact dates when the garbage truck will come to each neighborhood, street, or block. With this app, residents can simply input their location (barangay, street, or house number) and immediately see when the garbage truck will arrive to pick up their trash. This will help prevent missed collections, reduce time spent waiting, and ensure that trash is collected in a timely and organized manner

# Technologies Used 
- Flutter, Dart, and IoT

# Features 
- Real-time Bin Monitoring
- GPS Truck Locator
- Collection Schedules
- Interactive Maps and Collection Points
- Smart Alerts
